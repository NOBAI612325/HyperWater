# HyperWater 1.0 · 使用说明

## 前提

- HyperOS 4，有可用的临时 root（`su`）。
- 不需要 LSPosed，不需要 Shizuku，不需要换系统 APK。

## 步骤

1. 安装 `HyperWater-v1.0.0.apk`（versionCode 8）。
2. 打开 HyperWater，打开“开启高级材质”。
3. 在 root 授权弹窗允许。
4. 应用会：
   - 写入 22 个 `persist.sys` 属性（含原本缺失的 `persist.sys.bionic_material_supported`）；
   - 写入 3 个 `Settings.Secure` 开关；
   - **逐项读回验证**，状态栏显示“已写入并验证 N/N 项真实值”；
   - 自动重启设置进程。
5. 打开 **设置 → 显示与亮度**，应出现：
   - **高级材质**（开关）
   - **视觉风格**（进入可选 磨砂玻璃 / 软玻璃）
6. 若控制中心/通知面板还没变化，点 **“重启系统界面（让材质生效）”**。

重启 SystemUI 不会掉任何东西：写的是 `persist.*` 属性，重启界面后依然存在。

## 验证

“真实系统属性”卡片显示的是 `getprop` / `settings get` 读回的实际值：

```text
bionic_material_supported = true
background_blur_supported = true
secure background_blur_enable = 1
secure material_style = 1   (1=Bionics 高级材质)
advanced_visual_release = 4
```

## 恢复

点“恢复原始属性”，会把写入前的属性值和 Secure 值写回（原本不存在的键会 `settings delete`），并重启设置进程。

## 边界

- 需要 root；没有 root 就不会写，也不会假装成功。
- 不写 `/system`、`/vendor`、`/boot`，不替换任何 APK。
- 只写 `persist.sys` 与 `Settings.Secure`，可完整还原。

## 兼容性自检（不用 root）

打开应用时，“真实系统属性”卡片会先显示一份**只读自检**：

```text
机型 24129RT7CC · OS4.0 (code=4)
SF 背景模糊硬件支持 = 1
门控 bionic_material_supported = (未设置)
门控 background_blur_supported = (未设置)
→ 同代 HyperOS 4，门控名一致，可尝试
```

- `code=4` → 同代，门控名一致；
- 其他 code → 会提示“Bionics 门控可能不存在，写入后看未生效项”；
- `SF 背景模糊 ≠ 1` → 硬件不支持，直接拒绝写入。

写入后仍会逐项验证，未生效的会列出来，不会假装成功。

## 文件夹柔光玻璃

文件夹由桌面（`com.miui.home`）绘制，门控在桌面 APK 里，不在 Settings/SystemUI。应用已把：

- `persist.sys.launcher_blur_supported = true`
- `material_style = 1`（柔光玻璃）

写入，并提供 **“重启桌面（让文件夹柔光玻璃生效）”** 按钮让桌面重新读取属性。

## 锁屏

已加入 `persist.sys.background_blur_keyguard_disabled = false`（SystemUI 锁屏模糊总开关，原值为未设置）。
